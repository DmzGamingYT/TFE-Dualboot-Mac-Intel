# TFE — Dual-boot Mac Intel

[![GitHub](https://img.shields.io/badge/GitHub-DmzGamingYT/TFE--Dualboot--Mac--Intel-7a8f6b?style=flat-square&logo=github)](https://github.com/DmzGamingYT/TFE-Dualboot-Mac-Intel)

**Travail de fin d'études** · Installation et configuration d'un double amorçage macOS / Linux sur un MacBook Air 13" Early 2015.

## Machine cible

| Caractéristique | Valeur |
|---|---|
| Modèle | MacBook Air 13" Early 2015 · A1466 · EMC 2925 |
| Processeur | Intel Core i5-5250U · Broadwell · 1,6 GHz (Turbo 2,7 GHz) |
| Mémoire | 8 Go LPDDR3 1600 MHz · soudée |
| Stockage | SSD flash PCIe · 128 ou 256 Go |
| Wi-Fi | Broadcom BCM4360 · 802.11ac |
| Bluetooth | 4.0 · Broadcom BCM20702 |
| Graphique | Intel HD Graphics 6000 |
| Écran | 13,3" · 1440×900 · non Retina |
| Firmware | EFI 2.x · sans puce T2 |

## Utilisation

Ouvrir `index.html` dans un navigateur. Le document inclut :

- **Mode sombre** (bouton 🌙/☀️ dans la barre de navigation)
- **Toggle macOS / Linux** pour basculer l'accent visuel
- **Export PDF** via le bouton ⎙ PDF (optimisé pour A4)
- **Mode présentateur** pour la soutenance (15 min chrono intégré)
- **Checklist interactive** pour la préparation
